Was gehört zu einer Willenserklärung?

Eine Willenserklärung ist die Äußerung einer Person, mit der sie einen bestimmten rechtlichen Erfolg erreichen will, zum Beispiel einen Kaufvertrag. Ohne Willenserklärung gibt es kein Rechtsgeschäft: keinen Vertrag, keine Kündigung, kein Testament.

Eine Willenserklärung ist wie ein Eisberg. Ein Teil ist für alle sichtbar, ein Teil liegt verborgen unter Wasser.

Der innere Tatbestand: das Gewollte

Der innere Tatbestand hat drei Elemente. Achten Sie besonders auf die farbigen Felder: Was passiert, wenn das Element fehlt?

1

Handlungswille

Die Person handelt bewusst und gewollt.

Beispiel:

Bei einer Versteigerung wird Max von einer Wespe gestochen. Vor Schreck reißt er den Arm hoch. Der Auktionator hält das für ein Gebot.

Fehlt der Handlungswille:keine WillenserklärungEin Reflex, eine Bewegung im Schlaf oder unter Hypnose ist keine gewollte Handlung. Max muss nichts kaufen.
2

Erklärungsbewusstsein

Die Person weiß, dass ihr Verhalten eine rechtlich bedeutsame Erklärung sein kann, mit der sie sich bindet.

Beispiel:

Herr Weber betritt einen Saal, in dem Wein versteigert wird. Er winkt einem Freund zu. Bei einer Versteigerung heißt Handheben aber: „Ich biete mehr.“ Herr Weber bekommt den Zuschlag, obwohl er nur grüßen wollte.

Fehlt das Erklärungsbewusstsein: umstrittennach herrschender Meinung trotzdem eine Willenserklärungwenn die Person bei normaler Aufmerksamkeit hätte erkennen können, dass ihr Verhalten so verstanden wird. Sie kann die Erklärung aber anfechten.
3

Geschäftswille

Die Person will ein ganz bestimmtes Geschäft mit genau diesem Inhalt abschließen.

Beispiel:

Kim will im Onlineshop eine schwarze Hose bestellen. Sie vertippt sich bei der Artikelnummer und bestellt eine grüne. Kim wollte bestellen, also ist das Erklärungsbewusstsein da. Die grüne Hose wollte sie aber nicht.

Fehlt der Geschäftswille:trotzdem eine WillenserklärungKim kann sie aber wegen Irrtums anfechten (§ 119 Abs. 1 BGB).
