# Was gehört zu einer Willenserklärung?

Kurzer Lernkurs in 5 Schritten für die berufliche Schule (Medizinische Fachangestellte, 10. Klasse):

1. Eisberg: „Das Erklärte“ und „Das Gewollte“ in den Eisberg ziehen
2. Äußerer Tatbestand: ausdrücklich, schlüssiges Verhalten, Schweigen
3. Innerer Tatbestand: Handlungswille, Erklärungsbewusstsein, Geschäftswille
4. Fall Lena (Daumen-hoch-Emoji)
5. Check: 4 Verständnisfragen und Übersicht

Fortschrittsbalken in Prozent, keine Anmeldung, funktioniert auf Handy, Tablet und Laptop.
Der Fortschritt wird nur im Browser des jeweiligen Geräts gespeichert.

## Veröffentlichen mit GitHub Pages

1. Auf github.com: **+ → New repository**, Name z. B. `willenserklaerung`, **Public**, **Create repository**.
2. **uploading an existing file** anklicken, `index.html` hineinziehen, **Commit changes**.
3. **Settings → Pages**: „Deploy from a branch“, Branch **main**, Ordner **/ (root)**, **Save**.
4. Nach 1 bis 2 Minuten erscheint die Adresse, z. B. `https://IHR-NAME.github.io/willenserklaerung/`.

Alles steckt in der einen Datei `index.html`. Für spätere Änderungen einfach eine neue `index.html` über **Add file → Upload files** hochladen.
